Sponsor tools: ClickHouse, AkashML and Semgrep. yeet is our core engine, not one of the three counted sponsors. yeetkit powers the live runner UI. PatchMedic is a local agent runner with enforced access boundaries. A dependency is code your application relies on. When that code needs a fix, our agent prepares a patch and runs the tests. Today we show the useful work and what happens when the agent tries to step outside its job.

Linux kernel, not a prompt.

Use keys without exposing them

The daemon replaces placeholder credentials for approved API calls. Real keys stay outside the agent.

Block protected file access

yeet enforces Linux kernel policy when the agent tries to open a protected file.

Stop unauthorized connections

Restrict where the agent and its subprocesses can connect. Watch allowed and denied attempts live.

Run where the work happens

Linux laptops, VMs, production servers and CI. Docker shares the host kernel—no image changes.

No agent cooperation. A bad instruction doesn’t grant new permissions.

File and socket access controls run through eBPF LSM hooks loaded by yeet. Credential substitution is performed by the trusted daemon, not by writing secrets into agent-owned TLS buffers. Compatible BPF LSM kernel support and privileged policy loading are required. Container cgroups must be enrolled; host administrators remain trusted. ClickHouse records collected evidence for the live UI.

Accounts, project missions and history persist locally. The daemon checks repository HEAD every five minutes and investigates an unchanged project every fifteen minutes. One configured project is supported at present. The model chooses read, write and validation tools inside a confined workspace. Publication is restricted to karans4/kb-demo-target; changes are proposed for review, never merged automatically.

One runner. Several layers.

Filesystem confinement uses bubblewrap Linux namespaces in addition to eBPF. yeet loads and streams the eBPF policy. The daemon credential executor applies HTTP route scope. No yeet Rust source modified.
